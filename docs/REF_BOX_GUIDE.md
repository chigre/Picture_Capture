# REF 框（参考词条/参见区域）

REF 框只记录扫描页中的参考跳转区域，不是 PDIC 词条线、PPP 插图，也不修改原扫描或切图。示例包括“见”“参见”“see also”“SYNONYMS”“ANTONYMS”等任意图文样式；**不预设蓝底规则**。

## 使用

1. 打开词典项目及扫描页，进入 **设置中心 → REF框**，设置字体、填充色/不透明度和默认框大小；默认系统推荐字体 16 号、普通非斜体、**空文字淡橙色 50% 不透明度、非空文字淡绿色 50% 不透明度**，均无边框、宽 2×字/行高、高 1×字/行高；两种颜色及透明度可分别调整，文字可单独显示/隐藏。**所有颜色项现在都在 HEX 输入框旁显示与当前颜色相同底色的「选色…」按钮**；按钮与输入框共享设置值，改动后直接更新色块并自动保存；不完整或非法 HEX 会显示「颜色无效」，拒绝写入项目设置。
2. 在 **画线… → 编辑'REF'** 启用编辑模式。在正文任意位置**单击**创建默认尺寸框，或**拖动**创建指定矩形。**单击已有框选中**，显示四条边中点和四角的八个编辑手柄，**拖动任意边或角调整大小**、拖动框内部整体移动；框附近的 **✎** 按钮或**双击框内**打开文字/挂靠序号编辑（从 000 开始），**只能单击 × 按钮删除**（不提供 Delete、Backspace、右键删除），**F2** 也可编辑文字。**× 默认只在 REF 被选中时显示**；可以在设置中心启用「编辑模式中所有 REF 一直显示 ×」以直接操作未选中的框；操作按钮位置可以选择 **上方靠右／上方靠左／右侧**，在图像边缘自动调换侧或靠内排放。普通浏览模式不会显示可点击的 ×，防止误删。Ctrl+Z/Ctrl+Y 可撤销/重做 REF 单文件修改。进入 REF 编辑模式时与框重叠的词条浮动输入框暂时隐藏，退出后自动恢复。
3. **设置中心 → REF框 → 采集 REF 样本**：回到主画布拖选一块完整的图案，松开即保存该局部 PNG（不保存整页）。【管理 / 删除样本】可查看已有图案。
4. **画线… → 识别'REF'**：对当前选择的页面范围以用户选择的**引导词图案**为锚点匹配并自动补充框。程序先对扫描图和样本进行**灰度与对比度归一化**，再尝试多个缩放尺寸（默认 **±25%**，设置中心可调整 0–50%），并小范围检查横纵方向的不同拉伸，以适应轻微纸页曲率；这比旧的直接 RGB + 三档缩放更能适应跨页纸色、亮度和印刷尺寸变化，但明显局部弯曲仍有漏检风险。没有样本则跳过。**匹配到引导词 (x,y,w,h) 后，自动 REF 从 x+w 开始，垂直居中对齐引导词，宽高使用「REF 默认宽度/高度（行高倍数）」配置。** 在页面右缘空间不足时不跨栏换行。已有的 REF 框（包括人工编辑过的）绝不由自动识别覆盖。匹配的框初始文本留空，必要时双击手工填写；新 REF 中心所在的 PDIC 正文切片决定自动挂靠序号，不能可靠归属时保持空值。

5. **画线… → OCR 'REF'**：按钮位于【编辑'REF'】之后，只处理所选页面范围内已经存在的 REF 框；没有 `.rbox` 的页面自动跳过，不创建新文件。针对每个未填写的 REF，按原图像素矩形（已考虑 EXIF 显示方向）局部裁切并调用**本机**共享 PaddleOCR/Tesseract；Lens 网络引擎不会被调用或上传图像。识别结果填入当前 REF 的 `text`，**已有人工文字保持不变**；空识别结果和单框 OCR 失败不清除数据。每页所有改动一次性进行有源指纹的原子写回，检查 OCR 前后的源图 SHA256 及 REF SHA256；其他窗口在 OCR 期间修改文件时拒绝覆盖。批处理可暂停/停止，不隐式保存 PDIC，不修改 PPP、SECTION、普通 OCR 缓存或图像。已完成页面单独落盘，停止不会撤回以前成功处理的页面。


## 数据格式

路径：项目的 `data/ref_box/<page>.rbox`；受管理的项目对应 `_PictureCapture/data/ref_box/<page>.rbox`。样本图片保存在同一目录下的 `samples/ref_sample_*.png`，只存用户主动采集的裁剪。

rbox 使用 UTF-8、制表符分隔的 CSV/TSV，新保存时**严格九列**：

```tsv
id	x	y	w	h	w.ww%	h.hh%	entry_index	text
1	40	220	52	26	5.20%	2.60%	13	参见 leave
2	88	310	60	24	6.00%	2.40%		see also
```

- `id`：本页唯一正整数；`x,y,w,h`：原图像素坐标与宽高。
- `w.ww%` / `h.hh%`：分别等于宽度或高度除以**原图显示方向的宽度** ×100，保留两位小数。分母沿用 PDIC 的 X% 和 Y% 的**统一宽度分母**，不是原图高度；例中原图宽 1000 px。EXIF 旋转时以实际显示方向宽度计算。
- `entry_index`：本页 PDIC 逻辑排序后的零起始序号；空表示尚未挂靠。
- `text`：框内显示文本；包含制表符或换行时使用标准 CSV 双引号转义。不包含隐藏的类别、候选、置信度或目标 ID。
- **显示规则**：保存文本为空或只含空格/换行时采用设置中心的「REF 未填写底色」，默认 `#ffe0b2`（淡橙）及不透明度 50%；文本非空采用「REF 已填写底色」，默认 `#c8e6c9`（淡绿）及不透明度 50%。两种颜色与不透明度均可独立设置。取消「显示 REF 框内文字」仅隐藏画布文字：**不修改 `.rbox`、不取消关联、不会把有文字的绿色框变成橙色**；编辑模式下仍可选中、移动、缩放及点击 ✎ 查看/修改文本。
- 已有的七列 `.rbox` 可直接读取且读取时不改写；首次人工修改或自动新增时保存为九列，原有 ID、坐标、关联、文字保持不变。新文件的百分比数据与像素尺寸交叉校验，尺寸不一致时拒绝覆盖。
- REF 字号与**主词条文本框**同一缩放规则：设置中 REF 自己的字号为基准；当主词条「跟随缩放」开启时按 (原图宽 × 显示缩放 / 1400) 调整，否则字号固定；文字样式仍使用 REF 的字体、加粗、斜体设置。
- REF 文件更新是**单一文件**原子替换：写前比对源 SHA256，验证后才发布界面状态。文件格式损坏或遭外部改动时拒绝覆盖。REF 独立撤销/重做只覆盖本页 .rbox，不宣称 PDIC/PPP 之间的多文件 Undo/Redo 安全。
- 没有图像网络上传、在线训练、真实扫描自动提交。样本只在本机项目下保存。
- **跨页匹配限制与后续方向**：模板只定位引导词，不做真实 REF 正文 OCR，也不能保证明显书页弯曲、透视变形或不同字体排版时的检出率。跨页仍漏检时，优先采集多个不同页的引导词样本、微调尺度容差/匹配阈值并人工核对结果；更进一步可引入本地 OCR 先识别“参见/见/SYNONYMS/ANTONYMS”等引导词，再用相对坐标生成 REF（需要单独的误报控制与测试）。

## 验收边界

合成回归测试涵盖 TSV（含带引号/换行文本）往返、外部修改阻止覆盖、损坏文件 fail-closed、单文件 Undo/Redo/清 redo、翻页、图案匹配与人工框保护；完整 Windows/macOS/Ubuntu/Python3.10 CI 不代表真人 Windows 软件交互已验收。

人工 Windows 检查：设置中心启用/自动保存；新建/拖框/移动/缩放/双击文字、挂靠从 000 计；仅点击 × 删除、撤销重做；关闭/重开页面及重新打开项目；在已有 PDIC/PPP/SECTION/Profile 项目上核实无改写；采集图案、查看样本、运行 1 页和范围批量识别并确认不会覆盖人工框。未通过该检查前不要宣称真人 GUI 验收。

限制：当前版本的图案匹配不自动 OCR REF 正文，也不基于 text 自动跳转目标词条；字段按用户要求仅包含七个业务字段与宽、高两个派生百分比字段。相关自动文字推断和跳转可以后续在不修改此七列合同的前提下增加。
