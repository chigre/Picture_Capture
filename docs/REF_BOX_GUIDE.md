# REF 框（参考词条/参见区域）

REF 框只记录扫描页中的参考跳转区域，不是 PDIC 词条线、PPP 插图，也不修改原扫描或切图。示例包括“见”“参见”“see also”“SYNONYMS”“ANTONYMS”等任意图文样式；**不预设蓝底规则**。

## 使用

1. 打开词典项目及扫描页，进入 **设置中心 → REF框**。目前分为**原图 REF 定位框**、**REF 文本标签**、**OCR REF 文本提取正则**和图样匹配/采集设置。定位框默认为**内部透明、橙/绿轮廓**，原图文字可直接看清；有 OCR 文本时会在原图框**右侧**以带底色的独立标签显示，右侧空间不足自动放到左侧。标签字体、字号、字色、加粗/斜体、背景色/透明度、边距以及显示/隐藏，均属于文本标签；它的屏幕坐标为显示状态，不会进入 .rbox。主词条字体的跟随缩放/固定策略仍适用。修改颜色可以通过可预览底色的「选色…」按钮完成。
2. 在 **画线… → 编辑'REF'** 启用编辑模式。在正文任意位置**单击**创建默认尺寸框，或**拖动**创建指定矩形。**单击已有框选中**，显示四条边中点和四角的八个编辑手柄，**拖动任意边或角调整大小**、拖动框内部整体移动；框附近的 **✎** 按钮或**双击框内**打开文字/挂靠序号编辑（从 000 开始），**只能单击 × 按钮删除**（不提供 Delete、Backspace、右键删除），**F2** 也可编辑文字。**× 默认只在 REF 被选中时显示**；可以在设置中心启用「编辑模式中所有 REF 一直显示 ×」以直接操作未选中的框；操作按钮位置可以选择 **上方靠右／上方靠左／右侧**，在图像边缘自动调换侧或靠内排放。普通浏览模式不会显示可点击的 ×，防止误删。Ctrl+Z/Ctrl+Y 可撤销/重做 REF 单文件修改。进入 REF 编辑模式时与框重叠的词条浮动输入框暂时隐藏，退出后自动恢复。
3. **设置中心 → REF框 → 连续采集 REF 样本**：先选择引导词类别（见、参见、亦作、同、别名、其他或自定义）和目标方向（向后/向前）；“别名”默认向前，其余默认向后。回到主画布连续拖框，每次松开保存一份局部 PNG 和一份独立 JSON 样本元数据（类别、方向），**不会自动退出采集**。右键或 Esc 退出；切换扫描页仍可继续采集。管理窗口按照类别分组，提供缩略图预览、类别/方向修改和删除。
4. **画线… → 识别'REF'**：对当前选择的页面范围以用户选择的**引导词图案**为锚点匹配并自动补充框。程序先对扫描图和样本进行**灰度与对比度归一化**，再尝试多个缩放尺寸（默认 **±25%**，设置中心可调整 0–50%），并小范围检查横纵方向的不同拉伸，以适应轻微纸页曲率；这比旧的直接 RGB + 三档缩放更能适应跨页纸色、亮度和印刷尺寸变化，但明显局部弯曲仍有漏检风险。没有样本则跳过。**匹配到引导词 (x,y,w,h) 后，根据该样本的方向生成 REF。**默认不勾选「图样宽度纳入画框」：向后时从 x+w 开始，向前时以 x 为右边界并向左延伸 REF 默认宽度。勾选后同时包含图样：向后时从 x 开始，向前时延伸到 x+w，**目标总宽为图样的实际匹配宽度 + REF 默认宽度**。两种方向均按引导词高度垂直居中并限制在原图边界；没有足够目标文本空间时跳过。 在页面右缘空间不足时不跨栏换行。已有的 REF 框（包括人工编辑过的）绝不由自动识别覆盖。匹配的框初始文本留空，必要时双击手工填写；新 REF 中心所在的 PDIC 正文切片决定自动挂靠序号，不能可靠归属时保持空值。

5. **画线… → OCR 'REF'**：按钮位于【编辑'REF'】之后，只处理所选页面范围内已经存在的 REF 框；没有 `.rbox` 的页面自动跳过，不创建新文件。针对每个未填写的 REF，按原图像素矩形（已考虑 EXIF 显示方向）局部裁切并调用**本机**共享 PaddleOCR/Tesseract；Lens 网络引擎不会被调用或上传图像。**OCR REF 文本提取正则**是可编辑的 Python 正则表达式，像词头提取正则一样直接显示在设置中心；有捕获组时使用第一个参与匹配的捕获组，没有捕获组时取完整匹配，未命中或正则留空则保留原 OCR 文本。默认规则提取成对“…”/‘…’中的内容，并兼顾左/右引号识别不完整的情形。识别结果填入当前 REF 的 `text`，**已有人工文字保持不变**；空识别结果和单框 OCR 失败不清除数据。每页所有改动一次性进行有源指纹的原子写回，检查 OCR 前后的源图 SHA256 及 REF SHA256；其他窗口在 OCR 期间修改文件时拒绝覆盖。批处理可暂停/停止，不隐式保存 PDIC，不修改 PPP、SECTION、普通 OCR 缓存或图像。已完成页面单独落盘，停止不会撤回以前成功处理的页面。


## 数据格式

路径：项目的 `data/ref_box/<page>.rbox`；受管理的项目对应 `_PictureCapture/data/ref_box/<page>.rbox`。样本图片保存在同一目录下的 `samples/ref_sample_*.png`，每张图对应 `ref_sample_*.json` 元数据（`category`、`direction`，后者为 `after` / `before`）；采集时只存用户主动采集的裁剪。

rbox 使用 UTF-8、制表符分隔的 CSV/TSV，新保存时**严格九列**：

```tsv
id	x	y	w	h	w.ww%	h.hh%	entry_index	text
1	40	220	52	26	5.20%	2.60%	13	参见 leave
2	88	310	60	24	6.00%	2.40%		see also
```

- `id`：本页唯一正整数；`x,y,w,h`：原图像素坐标与宽高。
- `w.ww%` / `h.hh%`：分别等于宽度或高度除以**原图显示方向的宽度** ×100，保留两位小数。分母沿用 PDIC 的 X% 和 Y% 的**统一宽度分母**，不是原图高度；例中原图宽 1000 px。EXIF 旋转时以实际显示方向宽度计算。
- `entry_index`：本页 PDIC 逻辑排序后的零起始序号；空表示尚未挂靠。
- `text`：框内显示文本；包含制表符或换行时使用标准 CSV 双引号转义。不包含隐藏的类别、候选、置信度或目标 ID。
- **显示规则**：原图 REF 定位框默认不填色（内部透明度 0%），始终保留轮廓以便核对原图字形；定位框空/非空状态对应淡橙/淡绿的可配置填色，仅在提高内部不透明度后显示。若保存的 `text` 非空，独立文本标签显示于框的右侧（右缘不足时向左），默认淡蓝底色 `#dceefc`、95% 不透明度、深蓝文本。定位框与文本标签分别开关，**文字颜色/字体/字号/底色/边距都在文本标签组中配置**；隐藏标签不会更改 `.rbox` 及挂靠。
- 已有的七列 `.rbox` 可直接读取且读取时不改写；首次人工修改或自动新增时保存为九列，原有 ID、坐标、关联、文字保持不变。新文件的百分比数据与像素尺寸交叉校验，尺寸不一致时拒绝覆盖。
- REF 字号与**主词条文本框**同一缩放规则：设置中 REF 自己的字号为基准；当主词条「跟随缩放」开启时按 (原图宽 × 显示缩放 / 1400) 调整，否则字号固定；文字样式仍使用 REF 的字体、加粗、斜体设置。
- REF 文件更新是**单一文件**原子替换：写前比对源 SHA256，验证后才发布界面状态。文件格式损坏或遭外部改动时拒绝覆盖。REF 独立撤销/重做只覆盖本页 .rbox，不宣称 PDIC/PPP 之间的多文件 Undo/Redo 安全。
- 没有图像网络上传、在线训练、真实扫描自动提交。样本只在本机项目下保存。
- **跨页匹配限制与后续方向**：模板只定位引导词，不做真实 REF 正文 OCR，也不能保证明显书页弯曲、透视变形或不同字体排版时的检出率。跨页仍漏检时，优先采集多个不同页的引导词样本、微调尺度容差/匹配阈值并人工核对结果；更进一步可引入本地 OCR 先识别“参见/见/SYNONYMS/ANTONYMS”等引导词，再用相对坐标生成 REF（需要单独的误报控制与测试）。

## 验收边界

合成回归测试涵盖 TSV（含带引号/换行文本）往返、外部修改阻止覆盖、损坏文件 fail-closed、单文件 Undo/Redo/清 redo、翻页、图案匹配与人工框保护；完整 Windows/macOS/Ubuntu/Python3.10 CI 不代表真人 Windows 软件交互已验收。

人工 Windows 检查：设置中心启用/自动保存；新建/拖框/移动/缩放/双击文字、挂靠从 000 计；仅点击 × 删除、撤销重做；关闭/重开页面及重新打开项目；在已有 PDIC/PPP/SECTION/Profile 项目上核实无改写；采集图案、查看样本、运行 1 页和范围批量识别并确认不会覆盖人工框。未通过该检查前不要宣称真人 GUI 验收。

限制：图样匹配步骤自身不执行 REF 正文 OCR，需使用独立的【OCR REF】按钮，也不基于 text 自动跳转目标词条；字段按用户要求仅包含七个业务字段与宽、高两个派生百分比字段。相关自动文字推断和跳转可以后续在不修改此七列合同的前提下增加。
