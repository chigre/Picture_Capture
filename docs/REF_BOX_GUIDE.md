# REF 框（参考词条/参见区域）

REF 框只记录扫描页中的参考跳转区域，不是 PDIC 词条线、PPP 插图，也不修改原扫描或切图。示例包括“见”“参见”“see also”“SYNONYMS”“ANTONYMS”等任意图文样式；**不预设蓝底规则**。

## 使用

1. 打开词典项目及扫描页，进入 **设置中心 → REF框**，设置字体、填充色/不透明度和默认框大小；默认系统推荐字体 16 号、普通非斜体、淡蓝底色不透明度 50%、无边框、宽 2×字/行高、高 1×字/行高。
2. 在 **画线… → 编辑'REF'** 启用编辑模式。在正文任意位置**单击**创建默认尺寸框，或**拖动**创建指定矩形。已有框内部拖动移动，右下角附近拖动改变尺寸；**双击**填写文字和本页主词条序号（从 000 开始），右键可删除或使用 REF 撤销/重做。
3. **设置中心 → REF框 → 采集 REF 样本**：回到主画布拖选一块完整的图案，松开即保存该局部 PNG（不保存整页）。【管理 / 删除样本】可查看已有图案。
4. **画线… → 识别'REF'**：对当前选择的页面范围以局部图案匹配自动补充框。没有样本则跳过；已有的 REF 框（包括人工编辑过的）绝不由自动识别覆盖。匹配的框初始文本留空，必要时双击手工填写；中心点所在的 PDIC 正文切片决定自动挂靠序号，不能可靠归属时保持空值。

## 数据格式

路径：项目的 `data/ref_box/<page>.rbox`；受管理的项目对应 `_PictureCapture/data/ref_box/<page>.rbox`。样本图片保存在同一目录下的 `samples/ref_sample_*.png`，只存用户主动采集的裁剪。

rbox 使用 UTF-8、制表符分隔的 CSV/TSV，**严格七列**：

```tsv
id	x	y	w	h	entry_index	text
1	40	220	52	26	13	参见 leave
2	88	310	60	24		see also
```

- `id`：本页唯一正整数；`x,y,w,h`：原图像素坐标与宽高。
- `entry_index`：本页 PDIC 逻辑排序后的零起始序号；空表示尚未挂靠。
- `text`：框内显示文本；包含制表符或换行时使用标准 CSV 双引号转义。不包含隐藏的类别、候选、置信度或目标 ID。
- REF 文件更新是**单一文件**原子替换：写前比对源 SHA256，验证后才发布界面状态。文件格式损坏或遭外部改动时拒绝覆盖。REF 独立撤销/重做只覆盖本页 .rbox，不宣称 PDIC/PPP 之间的多文件 Undo/Redo 安全。
- 没有图像网络上传、在线训练、真实扫描自动提交。样本只在本机项目下保存。

## 验收边界

合成回归测试涵盖 TSV（含带引号/换行文本）往返、外部修改阻止覆盖、损坏文件 fail-closed、单文件 Undo/Redo/清 redo、翻页、图案匹配与人工框保护；完整 Windows/macOS/Ubuntu/Python3.10 CI 不代表真人 Windows 软件交互已验收。

人工 Windows 检查：设置中心启用/自动保存；新建/拖框/移动/缩放/双击文字、挂靠从 000 计；右键删除及撤销重做；关闭/重开页面及重新打开项目；在已有 PDIC/PPP/SECTION/Profile 项目上核实无改写；采集图案、查看样本、运行 1 页和范围批量识别并确认不会覆盖人工框。未通过该检查前不要宣称真人 GUI 验收。

限制：当前版本的图案匹配不自动 OCR REF 正文，也不基于 text 自动跳转目标词条；字段按用户要求保持精简。相关自动文字推断和跳转可以后续在不修改此七列合同的前提下增加。
