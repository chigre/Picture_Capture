# 图解词典：空间词条框与多语言索引

本功能与传统 PDIC 画线、REF、插图 PPP、SECTION 完全独立；不修改传统词条、自动画线结果，也不处理图片内部已有的指向线。

## 打开与绘制

在【画线…】中点击【图解词典（自由文字框 / 全页 OCR）…】。独立窗口显示原始图片，可用上/下页按钮导航。

- 空白位置按下并拖动：新建原图坐标矩形，立即保存
- 拖动已有矩形内部：移动该框
- 按住 Shift、从已选框右下角拖动：调整宽高
- 双击框或【编辑选中】：编辑多行语言、主索引词和附加别名
- 【删除/拒绝】：已有框删除须确认；未保存的 OCR 候选不写盘
- 【显示转写标签】：控制独立 OCR 标签显隐，不覆盖原始图片文字

每个矩形对应一个文字组，不是每种语言单独建立一个独立词条。第一行默认为主索引词；其他行成为检索别名，仍可手动指定主索引词与额外别名。

页面文件位于项目 data/illustrated_entries/ 下；托管项目则为 _PictureCapture/data/illustrated_entries/。存储稳定 ID、源图 x/y/w/h、多语言 lines、primary、aliases、source 和 draft/reviewed 状态；不保存 target_point，也不识别图中引导线。保存过程使用单文件原子写入与哈希并发保护，不覆盖损坏数据。

## OCR 第二阶段

【全页 OCR 提议】使用共享 OCR 设置里的本地 Paddle/Tesseract，不访问联网 Lens。基于文本框位置、相对行高、垂直间距、文字左对齐/居中与实际水平重叠，提出多语言文字组；不预设栏位。

蓝色虚线表示尚未保存的 OCR 候选。可接受选中、接受全部或者清空候选。接受后的组为待校对，再双击人工确认。已保存人工框不会被重叠 OCR 候选静默覆盖。【框内 OCR】仅为尚无文字的现存框补字，不改已有人工文字。

空间分组结果是自动提议，仍须人工校验。多语言识别质量取决于本地已安装 OCR 引擎与其语言模型，可能出现错分、漏分、混合语言等情况。

## 导出索引

右侧选择当前页或全项目，再选：

1. 每组一条索引：一个文字组一行，保留 languages_json 和 aliases_json。
2. 多语言拆分索引：每种语言和附加别名各形成一条检索行；所有行仍共享同一个 group_id、原图矩形以及 primary。

结果为 exports/illustrated_dictionary/group_lookup.tsv 或 multilingual_lookup.tsv。此 TSV 是独立的图解词典检索索引中间产物，不改写工作 .pdic、传统 PicDic 图片裁切或现有词典打包。
