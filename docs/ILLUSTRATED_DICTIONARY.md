# 图解词典：空间词条框与多语言索引

本功能与传统 PDIC 画线、REF、插图 PPP、SECTION 完全独立；不修改传统词条、自动画线结果，也不处理图片内部已有的指向线。

## Project Profile 与动态菜单

【项目 Profile】和【一、版面参数】新增词典版式：

- 传统词典：沿用原来的分栏、行高、缩进及画线识别参数
- 图解词典：显示空间文字框设置，不需要栏位与横线
- 混合词典：用当前页的文件名设置「项目默认（传统）／传统／图解」覆盖；未覆盖页为传统模式

本字段和图解设置一起保存到项目 settings.json，并写入 Project Profile v3 的 illustrated 区块；不会将图解模式错误映射为 columns=1。项目 Profile 向导也可选择版式。更换版式只改变显示的工具和操作入口，不删除既有 PDIC、REF 或图解词条 JSON。

在图解页，【画线…】显示“主画布文字框编辑 / 校对”“全页 OCR 检测与文字组归并”“多语言索引导出”；传统页仍保留完整画线、REF 和插图菜单。主界面快捷操作“普/O/校”在图解页路由到图解编辑/OCR，而“存”提示图解标注已即时写盘，**不写传统 PDIC**。

OCR Profile 包括：主索引语言、OCR 语言集合、空间归并严格/自动/宽松、每组最大行数、审核要求、索引导出方式、上下与左右扫描排除百分比。排除边距仅影响整页 OCR 的检测区域，自动候选写入原图坐标。多语言集合采用本地 Tesseract 的 eng+fra+... 格式，使用前应安装对应语言包并在共享 OCR 中启用 Tesseract；不能把 Paddle 单语模型当成多语言引擎。

## 打开与绘制

在【四、图解词条】中选择【主画布文字框编辑 / 校对】，直接在主界面图片画布上操作。混合版式在切换图解页时自动显示相应标注，普通页仍使用原有 PDIC/REF 画布交互。

- 空白位置按下并拖动：新建原图坐标矩形，立即保存
- 拖动已有矩形内部：移动该框
- 按住 Shift、从已选框右下角拖动：调整宽高
- 双击框或【编辑选中】：编辑多行语言、主索引词和附加别名
- 【删除/拒绝】：已有框删除须确认；未保存的 OCR 候选不写盘
- 【显示转写标签】：控制独立 OCR 标签显隐，不覆盖原始图片文字

每个矩形对应一个文字组，不是每种语言单独建立一个独立词条。第一行默认为主索引词；其他行成为检索别名，仍可手动指定主索引词与额外别名。

页面文件位于项目 data/illustrated_entries/ 下；托管项目则为 _PictureCapture/data/illustrated_entries/。存储稳定 ID、源图 x/y/w/h、多语言 lines、primary、aliases、source 和 draft/reviewed 状态；不保存 target_point，也不识别图中引导线。保存过程使用单文件原子写入与哈希并发保护，不覆盖损坏数据。

## OCR 第二阶段

【全页 OCR 提议】使用共享 OCR 设置里的本地 Paddle/Tesseract，不访问联网 Lens。基于文本框位置、相对行高、垂直间距、文字左对齐/居中与实际水平重叠，提出多语言文字组；不预设栏位。

蓝色虚线表示尚未保存的 OCR 候选。可接受选中、接受全部或者清空候选。接受后的组为待校对，再双击人工确认。已保存人工框不会被重叠 OCR 候选静默覆盖。【框内 OCR】仅为尚无文字的现存框补字，不改已有人工文字。

空间分组结果是自动提议，仍须人工校验。多语言识别质量取决于本地已安装 OCR 引擎与其语言模型，可能出现错分、漏分、混合语言等情况。

## 导出索引

右侧选择当前页或全项目，再选：

1. 每组一条索引：一个文字组一行，保留 languages_json 和 aliases_json。
2. 多语言拆分索引：每种语言和附加别名各形成一条检索行；所有行仍共享同一个 group_id、原图矩形以及 primary。

结果为 exports/illustrated_dictionary/group_lookup.tsv 或 multilingual_lookup.tsv。此 TSV 是独立的图解词典检索索引中间产物，不改写工作 .pdic、传统 PicDic 图片裁切或现有词典打包。


## 网格、智能吸附、辅助线与对象布局编辑（A/B/C）

图解页使用主画布。按 **B** 进入创建框模式、**V** 进入对象选择模式；空白拖动新建矩形/框选，点击文字框选中，**Shift 或 Ctrl+单击** 追加/取消多选；拖动可整体移动已选对象；拖右下角控制点调整大小。所有几何数据是原图像素而不是缩放后的屏幕坐标。Shift 从顶部标尺向下拖动创建**水平辅助线**，从左侧标尺向右拖动创建**垂直辅助线**；Ctrl+拖动现有辅助线可移动。右键可删除附近辅助线、清除本页辅助线。网格/辅助线只存在标注显示层，原图不会被重写。

图解 PROFILE 新增网格 X/Y 间距、细分数、原点、颜色、近似不透明度、辅助线颜色、显示与锁定、网格/辅助线/对象吸附开关、吸附距离（以**屏幕像素**指定，随缩放换算）、方向键微移距离和撤销历史深度。每页辅助线存于 data/illustrated_entries/guides/<page>.json，与项目默认的网格参数分离。

右键操作菜单提供左/中/右对齐、顶/中/底对齐、水平/垂直等间距、等宽等高、组合/取消组合、锁定/解锁、隐藏/显示、复制、数值精确坐标、合并多语言文字组、从指定行拆分文字组，以及撤销/重做。**组合**仅联动几何移动，保留独立词条 ID 与语言；**合并文字组**则是显式的语义合并并将两个 OCR 词条变为一条，不可混为一谈。

快捷键：Ctrl+A 全选；Ctrl+G 组合；Ctrl+Shift+G 取消组合；Ctrl+D 原位偏移复制；Ctrl+C/V 在图解页复制/粘贴文本框（对象组保持联动、分配新 ID）；Ctrl+Z/Y 撤销重做；方向键移动、Shift+方向键加速；Delete 删除。OCR 检测产生未写盘的虚线候选，经右键【接受全部 OCR 候选】或菜单【接受本页 OCR 候选】确认后才存盘。传统词典页面不接收本模块的画布事件。

已增加纯几何、持久化及 Profile 回归测试；实际多语言 OCR 识别和鼠标 GUI 的人工验收仍需要真实项目运行。

图解对象的“拆分文字组”会按印刷行数量将源文本框垂直切分成**不重叠**的上下矩形，保留原来的语言文本顺序；这与仅在布局层组合多个独立词条不同。
