# Picture Capture 设置中心与画线参数参考

本文档说明主要设置的作用、改变后的影响以及常见调整思路。

> 维护规则：设置中心右侧【设置说明】按“作用 → 生效路径/前提 → 何时调整 → 调整方向/风险”维护。所有可编辑字段和复选项都应有专属说明；如果某字段仅为旧项目兼容、当前主流程不读取，也必须明确标注，不能用泛化的“高级参数”代替。

> 重要原则：
> 1. 主界面常用参数改动会短暂 debounce 后自动应用并保存。
> 2. 【设置中心】按任务分为“常用 / OCR画线（推荐） / 普通画线（备用） / 显示与校对 / 项目与批量 / 高级 / 排序 / 过滤规则”；设置同样自动应用/保存。
> 3. 所有真正影响词条/插图切图输出的参数统一在【切图设置】中。
> 4. 主界面与设置中心的页面位置统一使用原图 X/Y 像素；内部阅读方向/旋转只影响计算过程，不建立第二套用户坐标。【切图设置】同样使用原图 X/Y。

## 1. 第一次使用应该怎么设置

不要从“高级”页开始逐个调阈值。推荐顺序是：

1. 打开【项目 Profile】，确认词典语言、阅读方向、栏数、页眉/页尾和词头结构。
2. 回到主界面点【检测版面参数】，在一张典型页上检查栏线和正文范围。
3. 默认先在 1–3 张代表页运行【运行OCR画线（推荐）】。它同时利用文字、位置和结构证据，是当前主流程。
4. 只有词头始终紧贴栏左、正文缩进非常稳定，或 OCR 环境暂不可用时，再考虑【运行普通画线（备用）】。随后再扩大到批量范围。
5. 只有出现明确的“漏检模式”或“误检模式”时，再进入对应页的【高级设置】。

### 设置中心的分层

设置中心采用“左侧参数 + 右侧固定说明”的结构。鼠标停在设置项、点击 ⓘ，或用 Tab/鼠标进入输入框时，右侧会显示完整说明；表单本身只保留名称、控件和单位，避免所有解释同时铺开。

在【常用 → 常用版面参数】中，右侧说明区还会显示对应版面图解：正文栏数使用 `layout_col_number.png`；正文起始/结束 V、第一栏左缘 U、单栏正文宽度、栏间空白、典型行高和典型行间空白使用 `layout_settings.png`。图解只在这些设置项被选中时出现，并按说明区宽度等比缩放。


- **常用**：版面和语言。新用户主要看这里；包括正文栏数、正文起始/结束 V、第一栏左缘 U、单栏宽度、栏间空白、典型行高/行间空白和词头 OCR 语言。
- **OCR画线（推荐）**：默认主流程；包含识别带宽、左缘容差、图像预处理、横线安全距离，以及多 OCR 策略；CPU/GPU 由本机运行环境自动决定；候选分数/合并阈值放在高级区。
- **普通画线（备用）**：墨迹判断、左缘检测宽度、行高/行间空白；主要用于高度规则的左缘版式或 OCR 暂不可用时，高级项默认折叠。
- **显示 / 校对**：字体、词框、校对缩放、wordslist；这些不改变识别结果。
- **项目 / 批量**：项目资料、OCR运行环境、自动保存等。
- **高级**：书写方向、底层后端和正则。普通用户通常不需要修改。

主界面只保留高频项。OCR画线默认使用“有效缓存（推荐）”；缓存签名会在图像或真正影响原始 OCR 的后端设置变化时自动失效，因此无需每次强制重新识别。

## 2. Project Profile（推荐入口）

Profile 是一组“版面 + 语言语法 + OCR 判定 + 横线定位”的预设。先选择最接近的版面，再做少量 override，通常比逐个调高级参数稳定。

### 版面 Profile

- **拉丁字母 · 音标密集双栏**：英文粗体词头、音标/POS 紧跟、正文缩进明显。
- **拉丁字母 · 紧邻词性经典双栏**：葡语/意大利语经典双栏，左缘和 POS 是主要证据。
- **拉丁字母 · 编号词性双栏**：允许 `lemma → 编号 → POS`。
- **拉丁字母 · 结构符号词典型**：词性、变形、结构符号丰富的学习词典。
- **中文 · 圆点/拼音三栏**：○/●/〓 + 中文词头 + 拼音/罗马字。
- **中文 · 括号词头/大字三栏**：【】/〔〕词头及大字号单汉字词头。

### OCR 与语言

| 设置 | 作用 | 调整影响 |
|---|---|---|
| OCR 语言 | Tesseract/规则所用语言，可使用组合代码。 | 影响 OCR 字符模型、词性解析和排序预设。错误语言会降低词头文字准确度。 |
| PaddleOCR 语言 | PaddleOCR 模型语言。 | 应优先跟“词头语言”，而非释义语言。错误语言可能降低识别。 |

### 版式证据

| 设置 | 作用 | 增大/减小的影响 |
|---|---|---|
| 词典分栏 | 页面正文栏数。 | 错误会导致栏号、排序、切图水平边界均不正确。 |
| 候选带宽比例 | OCR 每栏左侧实际分析宽度占 Profile 原候选带的比例。 | 增大：更容易包含远离左缘的 POS/音标，但正文噪声更多；减小：更快、更干净，但长词头可能缺结构提示。 |
| 候选带左侧余量 | 候选带相对栏左的额外余量。 | 增大可容忍扫描偏移；太大会纳入邻近内容。 |
| AI 左缘容差 | 允许候选首墨迹离栏左多远。 | 增大提高召回但可能把正文续行当词头；减小提高精确度但可能漏掉缩进词头。 |
| AI 字高比阈值 | 候选字高相对正文基准的要求。 | 增大更强调大字号词头；过高会漏普通字号词头。 |
| AI 粗体比阈值 | 候选墨迹粗重程度要求。 | 增大更强调粗体；二值扫描或非粗体词典不宜过高。 |
| AI 行前空白比 | 行前空白作为词头证据的强度。 | 只适合空白明显的版式；普通行与词头空白相近时不要依赖它。 |
| AI 最低候选分 | 综合证据最低接受分。 | 增大减少假阳性但增加漏词；减小提高召回但需更多人工复核。 |
| AI 词性搜索字符数 | 从词头起向右搜索 POS/结构的最大文本长度。 | 增大适合音标很长或中间有编号的词典；太大可能吸收释义结构。 |

### 识别行为

- **候选必须具有结构/视觉提示**：要求候选至少有粗体/字号/左缘等视觉或结构证据。关闭后召回更高，但假阳性明显增加。
- **候选必须有词性/变形/词条符号**：适合 POS 明确的拉丁词典；中文结构型 Profile 通常由 Profile 自身解析逻辑代替传统 POS。
- **去除词头音节分隔点**：把词典排版中的音节分隔点清理为正常 lemma。对于真实词形中需要保留标点的词典应谨慎。
- **自动忽略页眉横线以上**：检测典型页眉横线，将其以上内容排除出正文候选。
- **词头横线 Y 按栏内墨迹谷精修**：OCR 只负责粗定位，再利用图像空白/低墨迹谷把横线放到更稳定的位置。

### 横线定位

| 设置 | 作用 | 调整影响 |
|---|---|---|
| 横线Y精修搜索范围（行高比） | 在 OCR 粗定位附近上下搜索的范围。 | 过小找不到真实白缝；过大可能跳到相邻行间隙。 |
| 横线Y精修安全带半径 | 计算局部墨迹谷时的带宽。 | 增大更平滑；过大可能抹掉窄白缝。 |
| 横线Y精修安全空间 | 最终横线与检测墨迹之间额外留白。 | 增大横线更远离文字；太大可能落到上一/下一行区域。 |
| 横线Y精修横向分析范围 | 只分析栏左侧多少百分比。 | 减小可避免长释义文字干扰；太小可能看不到完整词头。 |
| 横线Y精修栏边余量 | 避开栏边框/扫描边缘的横向余量。 | 适度增加可排除栏线噪声。 |

## 3. 高级参数参考（按底层字段列出）

### 版面几何

| 设置 | 含义 | 主要影响 |
|---|---|---|
| 两栏中隔 | 原图像素中的栏间空白宽度。 | 影响栏几何、词头所属栏及水平切图边界。 |
| 单栏宽距 | 原图像素中的单栏宽度。 | 影响栏位置、OCR候选带与词条切图基础范围。 |
| 正文起始 Y | 原图像素中的正文起始 Y。 | 直接限定正文起始位置，不按页面宽度缩放。 |
| 第一栏左缘 X | 原图像素中的第一栏左缘 X。 | 直接限定栏左位置，不按页面宽度缩放。 |
| 正文缩进 | 普通正文相对栏左的典型缩进。 | 左缘规则区分词头与续行的重要参考。 |
| 单行字高 | 典型行高。 | 用于行检测、OCR合并和 Y 精修尺度。 |
| 行间空白 | 典型行间空白。 | 用于行步长、传统检测和版面估计。 |
| 向右比例 1/ | 旧算法的水平分析比例参数。 | 主要影响传统版面/左缘分析范围。 |
| 微调判距 | 几何匹配允许的水平误差。 | 增大容忍扫描偏移，同时可能错误合并。 |
| 黑色阈值 RGB 和 | 像素是否视为“墨迹”的阈值。 | 提高/降低会改变纯图像检测对浅灰文字/噪声的敏感度。 |

> 当前项目设置只使用原图 X/Y 像素。像素参数不会按窗口宽度、页面宽度或 1400px 基准缩放；`geometry_reference_width` 与旧显示宽度只用于一次性读取/迁移历史项目。

### 词条线显示

- **标记线高**：词头横线显示高度；主要影响界面显示，不改变词头 Y 数据本身。
- **垂直线宽**：栏左参考垂线显示宽度；主要是视觉辅助。

### 主界面词条文本框

- **主界面字体**：词条 Entry 字体。
- **主界面字号（100%）**：页面缩放 100% 时的字号；随页面缩放同步缩放。
- **主界面词框宽度（字符）**：文本框视觉宽度。
- **主界面词框横向位置（栏宽比例）**：文本框显示在栏中的相对 X 位置，只影响编辑控件布局，不修改词条坐标。
- **字体样式：粗体/斜体**：仅界面显示。

### 词条校对文本框

- **校对界面字体/字号**：校对窗口独立字体。
- **校对默认缩放（%）**：校对窗口初始图像缩放；与主界面缩放独立。
- **粗体/斜体**：仅校对显示。

### 辅助词表

- **wordslist.txt 位置**：用于主界面成员提示与校对窗口右侧参考词表。
  - 项目内路径保存为相对路径，便于项目迁移。
  - 项目外文件保存绝对路径。
  - 词表可很大；程序建立完整成员索引，但 GUI 只渲染当前词附近窗口。

### 列跟踪

用于“跟随词头列倾斜和局部变形”。

- **列跟踪搜索半径**：每块允许左右寻找栏位置的范围。太小跟不上明显弯曲/倾斜，太大可能跳到邻栏。
- **列跟踪分块高度**：沿 Y 方向每次估计栏位置的块高。小块更灵活但更容易受局部噪声影响。
- **列跟踪最大步移**：相邻块允许的最大 X 跳变。用于抑制错误跳栏。

### 插图识别

- **插图自动识别外扩（px）**：自动检测框四周的基础扩边。
- **插图自动识别右侧外扩（px）**：右边界独立扩边。经典词典插图常向栏间空白伸出，因此默认通常大于其他方向。

这两个参数只影响自动识别得到的 PPP 初始轮廓；之后可人工编辑。

### OCR 基础

- **PaddleOCR 运行设备**：不再作为项目设置保存。程序按当前机器实际 Paddle runtime 自动选择 CPU/GPU；项目从 Windows/Linux GPU 机器复制到 macOS/CPU 机器时不会继承旧 GPU 设置。高级排错可临时使用环境变量 `PICTURE_CAPTURE_PADDLE_DEVICE=cpu` 或 `gpu`。
- **Tesseract 可执行程序**：由【环境中心】保存为本机 runtime 设置；旧项目中的历史路径只作为兼容发现提示，不再覆盖当前机器的 PATH/Homebrew 等正常发现。
- **PaddleOCR 模型版本**：当前默认 PP-OCRv6。
- **自动保存间隔（秒）**：自动保存相关间隔；过短会增加频繁磁盘写入。

### PaddleOCR 候选与版面（高级）

- **AI 候选置信度**：OCR 文本置信度下限。
- **AI 同行合并Y比**：把多个 OCR box 判为同一印刷行的 Y 容差比例。提高可合并分裂 box，但可能把相邻行合并。
- **页眉横线搜索高度**：从顶部多高范围搜索横向规则线。
- **页眉横线墨迹比例**：一行中要有多少连续/总体墨迹才视为页眉横线。
- **页眉横线后余量**：检测到页眉线后，再向下留多少安全空间才开始正文。

### 多 OCR / Google Lens

- **Tesseract 对照 PSM**：Tesseract 页面分割模式；词典候选带常见 4/6。
- **Google Lens OCR语言**：Lens 请求的语言提示。
- **Google Lens 超时**：网络调用最长等待时间。
- **Lens无置信度默认值**：Lens 不返回可用置信度时参与融合的默认质量值。
- **双OCR Y容差（行高比）**：Paddle 与 Tesseract 候选在 Y 上多近才可配对。
- **双OCR 最低lemma相似度**：两个 OCR 文字相似度低于此值时不视为同一候选。
- **冲突自动选择质量差**：两个引擎质量差达到多少才自动选较优者；较小更积极自动决策，较大更多留给人工复核。

### 词头识别正则（高级）

这三项处在不同阶段，不是三个并列的“识别模型”：

```text
OCR 合并行
   ↓
AI 词头提取正则 —— 先回答“这一行开头能否抽出一个合法 lemma？”
   ↓
语法解析 / AI 词性提示正则 —— 再找 POS、变形等结构证据
   ↓
AI 特殊符号正则 —— 补充“行首是否有新词条标记”的证据
   ↓
结合左缘位置、视觉分数、Profile grammar 等决定是否接受
```

#### AI 词头提取正则

**作用对象**：一整条已合并的 OCR 候选行。  
**输出**：若正则有捕获组，程序把**第 1 捕获组**作为原始 lemma；没有捕获组时才使用整个匹配。

当前默认规则的设计意图：

- 必须从行首开始（`^`），但允许前导空格。
- 允许行首出现一个可选项目符号：`• ◆ ◇ ► ▶ * † ‡ § ¶`。
- 主体接受 Unicode 字母，排除数字、下划线和普通标点。
- 允许前置/后置连字符，例如 `-able`、`anti-`。
- 允许音节分隔点 `· • ∙ ‧`，并容忍 OCR 把分隔点误识为 `.`、`:`、`+`、`-`。
- 允许撇号连接，例如 `l'homme`、`d’Artagnan`。

例如：

```text
• a·ga·rrón s. m. ...  →  a·ga·rrón
anti- adj. ...          →  anti-
l'homme s. ...          →  l'homme
```

**修改风险**：第 1 捕获组应只包 lemma。写得过宽，可能把逗号、POS 或释义正文吞进词头；写得过窄，合法词头会在后续评分之前直接消失。若保持内置默认值，Latin Profile 会在运行时把通用 Unicode 字母类收窄为拉丁字母；自定义正则则按用户写法原样使用。

#### AI 词性提示正则

**作用**：在 lemma 后的有限字符范围内寻找 POS/语法标签，作为“这是词条起始行”的强结构证据；它**不提取 lemma**。搜索距离还受【AI 词性搜索字符数】控制。

默认兼容规则覆盖常见西班牙语词典缩写，例如：

`s.`、`s. m.`、`s. f.`、`s. amb.`、`s. pl.`、`adj.`、`adj. inv.`、`adv.`、`v.`、`v. prnl.`、`prep.`、`conj.`、`pron.` 及其子类、`det.`、`interj.`、`art.`、`num.`、`loc.`、`superlat.` 等。`y.` 也被接受，是为了容忍 OCR 把 `v.` 识成 `y.`。

**非常重要的生效规则**：新版主程序通常会加载 Dictionary Profile。存在活动 Profile 时，实际 POS 正则由 Profile 的 `pos_labels` 动态生成，设置中心里的 **AI 词性提示正则主要是兼容/低层 fallback**。因此当前项目若已有 Profile，要增删词性缩写应优先修改 Profile grammar / `pos_labels`；否则可能出现“改了这里但主流程没有变化”的情况。

#### AI 特殊符号正则

**作用**：判断**行首**是否有可作为“新词条起始”证据的项目符号。默认：

```text
^s*[•◆◇►▶*†‡§¶]
```

即允许前导空格，然后必须马上出现 `• ◆ ◇ ► ▶ * † ‡ § ¶` 中的一个。它只是候选评分/结构判断的一项辅助证据，并不是“命中符号就无条件接受”。

例如：

```text
◆ palabra ...       → 命中特殊符号
   † antiguo ...    → 命中特殊符号
texto ◆ referencia  → 不命中（符号不在行首）
```

只应把真正表示“新词条/新条目起始”的符号放进这里。词条内部的释义标记、交叉引用和文章结构符号应由 Dictionary Profile 单独描述；例如某些词典中的 `■`、`□`、`||`、`~`、`→` 可以是**词条内部结构**，不应因此触发新 lemma。

**建议修改顺序**：先看 Project Profile → 再用词头过滤规则处理项目特例 → 最后才直接修改这三条正则。

## 4. 识别方式

### 词条行识别方式

- **PaddleOCR / OCR画线（推荐）**：识别候选文字、结构和位置，是默认主流程；真实词典存在缩进、粗体、词性和特殊符号变化时，优先从这里开始。
- **普通画线（备用）**：主要依赖几何、栏左墨迹和正文缩进，速度快、不需要 OCR 文本模型，但证据更少。它适合左缘高度规则的简单版式或 OCR 暂不可用时；底色明显不均时可在【普通画线（备用）】页改为“自适应”。

### OCR 引擎

详细设置中的 OCR 引擎用于某些单引擎路径；主界面 OCR 画线实际可以同时勾选多个 OCR 来源。

### Google Lens 模式

- **冲突时调用**：仅 Paddle/Tesseract 不一致或缺失时调用，网络开销较低。
- **诊断/全量类模式**：可能对更多候选调用 Lens；速度更慢，取决于网络。

## 5. 行为复选框

### 版面行为

- **使用自动版面参数**：仅作用于普通画线。开启后，每一页画线前先检测该页版面；其下可独立勾选 **分栏数 / 正文起始Y / 首栏X / 单栏宽 / 栏间空 / 单行高 / 行间空**，只把勾选字段临时替换为当前页检测值，逐页结果不写回下一页。
- **跟随词头列倾斜和局部变形**：每个 Y 区段动态跟踪栏左位置，适合弯曲、斜拍或书脊变形。三个调节量均改为相对比例：搜索范围按单栏宽百分比、分块高度按正文有效高度百分比、最大局部斜率按分块高度百分比。默认分别为 **5% / 3% / 8%**。

普通画线不再使用旧【手动分栏 / 手动模式起始Y】流程。正文结束位置也不再由主界面 bottom_y 人工控制：普通页使用原图高度，Project Profile 指定页底时使用 height × (1-页底百分比)，存在 SECTION 时由 SECTION 边界进一步限定。

### OCR 处理

- **OCR 后执行替换**：执行已有 OCR 归一化/替换规则。
- **OCR 转小写**：将 OCR 词头转小写；不适合大小写本身有词典意义的项目。

### 多 OCR 行为

- **Paddle检测同时运行Tesseract对照**：提供第二 OCR 结果用于比较。
- **Tesseract结果可补漏Paddle词头**：允许 Tesseract 独有候选进入最终词头集合。提高召回，但也可能增加假阳性。
- **Tesseract自动比较 PSM 4/6**：对照多个 PSM 选较适合结果，增加少量计算时间。
- **多OCR自动融合决策**：按序列/Y/文字相似度融合多个 OCR，而不把 Tesseract仅当诊断。
- **每个OCR左缘候选行显示复选框**：在主图显示人工确认控件。关闭可让界面更简洁，但失去逐候选快速人工覆盖入口。

## 5. 词头排序页

排序只用于词头顺序检查与相关显示/校对，不会改变扫描图片物理顺序。

- **自动**：根据 OCR 语言选择排序规则。
- **Unicode**：按 Unicode/文本规则。
- **自定义**：使用自定义字母顺序，可定义 `ch`、`ll` 等多字符排序单位。
- **折叠重音**：排序时把重音字母折叠到基础字母；只影响排序键，不改词头文字。

## 6. 词头过滤规则页

用于对 OCR 候选做项目级接纳/排除，适合不值得写进程序或 Profile 的特定词典规则。

支持导入/导出规则，示例见 `examples/headword_filter_rules.example.txt`。

典型用途：

- 排除固定页眉/页脚词。
- 排除特殊符号开头的非词条行。
- 允许某些词形、词性或绑定词素。
- 对 OCR 经常误认的固定模式做项目级修正。

## 7. 主界面快速设置

有明确数值范围的设置在设置中心中使用 Spinbox，并在输入框旁直接显示 px / % / 秒 / 栏等单位。设置会自动保存；底部状态会提示“正在自动保存 / 已保存 / 当前输入暂未保存”。关闭窗口、Esc 和右上角关闭按钮都会先校验当前值；Ctrl+S 只校验并保存，不关闭窗口。

主界面只保留高频快捷项：版面几何、OCR语言、识别带宽、左缘容差、OCR来源与缓存策略。候选置信度、最低候选分、同行合并等底层阈值移到【设置中心 → OCR画线 → 高级设置】，避免首次使用时误调。

颜色按钮仅控制叠加层显示，不改变 PDIC/PPP 数据。

## 8. 切图设置

这是唯一应该调整“最终切图”的地方。

| 设置 | 功能 | 影响 |
|---|---|---|
| 一般页切图上边界 Y（原图） | 原图像素中的裁剪起点。 | 直接使用原图 Y，不按页面宽度缩放。 |
| 一般页切图下边界 Y（原图） | 原图像素中的裁剪终点；0 = 页面底部。 | 直接使用原图 Y。 |
| 词条左侧额外留白 | 在自动计算的词条水平区域左侧再扩展。 | 只改变导出图片，不修改 PDIC。 |
| 词条右侧额外留白 | 在自动计算的水平区域右侧再扩展。 | 用于保留靠右释义/插图边缘。 |
| 是否综合插图计算切图信息 | 决定 PPP 是否参与词条 Crop Plan。 | 开启时可联合/扩框；关闭时词条只按自身矩形。 |
| PPP多边形外扩 | 独立 PPP 导出时对包围框额外扩展。 | 不修改 PPP 原始顶点。 |
| 并行进程 | 词条/插图切图的页面级并行度。 | 0=自动；值越大通常越快但内存占用更高。最大 8。 |
| 特殊页面上/下边界 Y | 对个别页面覆盖一般页边界。 | 保存为原图 Y 像素，其余切图设置共用。 |

### 词条切图水平边界

基础水平边界会根据栏几何和相邻栏间空白中线计算，不建议通过“单栏宽”硬把切图撑宽；需要额外上下文时使用“词条左/右额外留白”。

### 插图参与逻辑

**综合插图开启**：

1. 先生成 Crop Plan。
2. 有关联 PPP 的词条优先处理。
3. 完整包含 PPP：随词条输出。
4. 部分相交 PPP：词条矩形与 PPP 多边形联合。
5. 完全外部 PPP：单独 `(P数字).png`。
6. 普通词条切图前对无关 PPP 做填白，避免邻近插图污染。

**综合插图关闭**：

- 词条本身不扩框/联合，也不因 PPP 改变切图顺序。
- 内部 PPP 自然留在词条图中。
- 部分超出/外部 PPP 单独导出。

## 9. 页面列表相关设置

页面列永久显示；以下列可通过表头右键隐藏：

- 已画线
- 填充状态
- 插图

显示状态按项目保存。栏头排序是全项目排序，但只改变列表显示顺序，不改变图片/PDIC 的实际页面顺序。
