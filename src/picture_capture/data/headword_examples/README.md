# Project Profile headword example crops

Place small, tightly cropped example images for Wizard step ③ in this directory.

Naming lookup order:

1. `<profile_key>_<dictionary_name>.png`
2. `<dictionary_name>.png`
3. `<profile_key>.png`

Supported extensions: PNG, JPG/JPEG, WEBP.

Examples:

- `latin_regular_NewApproach.png`
- `latin_regular_LDER.png`
- `numbered_prefix_RUIGO.png`
- `cjk_visual_HZYLDZD.png`
- `cjk_visual_XDHYCD.png`
- `cjk_visual_TimesCED.png`
- `cjk_visual_shueisha.png`
- `edge_visual_regular_XAHDCD.png`

Keep crops visually comparable: use the same approximate canvas size, include one or two complete headwords plus enough adjacent text to make the entry boundary understandable, and avoid full-page screenshots.
